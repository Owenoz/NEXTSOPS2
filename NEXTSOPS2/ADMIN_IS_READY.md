## 🐛 Troubleshooting:

### If styles look plain:
```bash
# In your terminal, press Ctrl+C to stop
# Then run:
cd admin
rm -rf .next
npm run dev
```

### If page won't load:
1. Check the terminal for errors
2. Make sure you're on http://localhost:3002
3. Try hard refresh: Ctrl+Shift+R (Windows/Linux) or Cmd+Shift+R (Mac)

### If port is in use:
```bash
# Find and kill the process
lsof -i :3002
kill -9 <PID>
# Then start again
npm run dev
```
